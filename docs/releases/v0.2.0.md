## Link-Suite 0.2.0

**DE** – Der Launcher der Link-Suite. Er zeigt alle Programme, installiert und aktualisiert LJ Link, VJ-Link und
LJL Link (für den Club-Stick) direkt aus den GitHub-Releases und startet installierte Apps und Entwicklerprojekte.
Geprüft wird jede Datei: nur GitHub über HTTPS, Größe, SHA-256 aus der GitHub-API, Inhalt (genau eine App, Kennung,
Version); signierte `SHA256SUMS` werden geprüft, sobald ein Suite-Schlüssel eingetragen ist. Dazu Suite-Chat mit
EMERGENCY und IM NETZ. Keine Telemetrie, kein Konto; ins Internet nur zu GitHub.

Nicht signiert (macOS ad hoc, Windows ohne Authenticode): beim ersten Öffnen *Systemeinstellungen → Datenschutz &
Sicherheit → Dennoch öffnen* bzw. *Weitere Informationen → Trotzdem ausführen*.

**EN** – The launcher of the Link-Suite. It shows all programs, installs and updates LJ Link, VJ-Link and LJL Link (for
the club stick) straight from the GitHub releases, and starts installed apps and developer projects. Every file is
checked: GitHub over HTTPS only, size, SHA-256 from the GitHub API, content (exactly one app, bundle ID, version);
signed `SHA256SUMS` are verified once a suite key is configured. Plus suite chat with EMERGENCY and ON THE NETWORK. No
telemetry, no account; online only to GitHub.

Not signed (macOS ad hoc, Windows without Authenticode): on first launch use *System Settings → Privacy & Security →
Open Anyway* or *More info → Run anyway*.
