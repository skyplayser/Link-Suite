## Link-Suite 0.3.2

**DE** – Der Launcher der Link-Suite. Er zeigt alle Programme in Gruppen (installiert, Entwicklung, verfügbar, kommt
bald), installiert und aktualisiert LJ Link, VJ-Link und LJL Link (für den Club-Stick) direkt aus den GitHub-Releases und
startet installierte Apps und Entwicklerprojekte. Neu in 0.3: aufgeräumte Programmkarten mit einer Zustands-Pille,
Startanimation, in der die Programme in ihre Karten fliegen, macOS-Feinschliff (Fenster ohne Titelleiste, Menüs mit
Tastenkürzeln, Über-Fenster, Dock-Fortschritt und -Badge, stille Mitteilungen, Menüleisten-Symbol, DMG-Fenster),
Startlog für Fehlermeldungen und ein robuster Fensterstart unter Windows. Geprüft wird jede Datei: nur GitHub über HTTPS,
Größe, SHA-256 aus der GitHub-API, Inhalt (genau eine App, Kennung, Version). Keine Telemetrie, kein Konto; ins Internet
nur zu GitHub.

0.3.2 findet installierte Programme unter Windows schnell und zuverlässig (gezielte Registry-Suche, letzter Stand
sofort beim Start) und zeigt bekannte Releases auch ohne Netz. Seit 0.3.1 unter Windows: Updates mit Administratorrechten (Installer öffnet sich mit UAC-Abfrage), stabilere
Erkennung installierter Programme, „läuft“-Anzeige, ruhige Kartenordnung, eigene Texte für Windows und einen schlankeren
Installer (pro Benutzer, Deutsch/Englisch). Firewall-Regeln, die Windows beim ersten Start anlegt, bleiben beim
Deinstallieren stehen (dafür bräuchte es Administratorrechte).

Nicht signiert (macOS ad hoc, Windows ohne Authenticode): beim ersten Öffnen *Systemeinstellungen → Datenschutz &
Sicherheit → Dennoch öffnen* bzw. *Weitere Informationen → Trotzdem ausführen*.

**EN** – The launcher of the Link-Suite. It shows all programs in groups (installed, development, available, coming
soon), installs and updates LJ Link, VJ-Link and LJL Link (for the club stick) straight from the GitHub releases, and
starts installed apps and developer projects. New in 0.3: cleaner program cards with one status pill, a start animation
in which the programs fly into their cards, macOS polish (window without title bar, menus with shortcuts, About window,
Dock progress and badge, silent notifications, menu bar icon, DMG window), a startup log for bug reports and a robust
window start on Windows. Every file is checked: GitHub over HTTPS only, size, SHA-256 from the GitHub API, content
(exactly one app, bundle ID, version). No telemetry, no account; online only to GitHub.

0.3.2 finds installed programs on Windows quickly and reliably (targeted registry search, last state shown right at
start) and keeps showing known releases without a network. Since 0.3.1 on Windows: updates that need administrator rights (the installer opens with the UAC prompt), steadier
detection of installed programs, the “running” display, a calm card order, Windows-specific texts and a leaner installer
(per user, German/English). Firewall rules that Windows creates on first start remain after uninstalling (removing them
would need administrator rights).

Not signed (macOS ad hoc, Windows without Authenticode): on first launch use *System Settings → Privacy & Security →
Open Anyway* or *More info → Run anyway*.
