2 · The Link-Suite program

Link-Suite runs on your computer and in your local network. It sends no usage data, no crash reports and no telemetry, and we receive no data from the program.

Requests and downloads from GitHub

To find new versions, Link-Suite asks the public interface api.github.com for the latest release of each suite program: on every start of Link-Suite if “Check for updates at start” is on (on by default), at most once an hour while Link-Suite is running, when you click “Check all” and before an installation if there is no fresh state yet. It always asks about all suite programs alike, so without a list of your installed programs. Link-Suite only starts downloads when you click, from github.com and GitHub's download servers; this also applies to updates of Link-Suite itself. GitHub receives your computer's IP address and the identifier Link-Suite/<version>. GitHub's privacy terms apply. You can switch the automatic check off under Settings → Programs.

Suite chat and ON THE NETWORK

Link-Suite has a chat room for the suite programs on the same local network, without a server. It is on by default and can be switched off under Settings → Suite chat; Link-Suite then sends and receives nothing, and ON THE NETWORK stays empty.

What is sent: While the chat is on, Link-Suite sends via UDP multicast (group 239.255.76.76, port 47676, time-to-live 1, not forwarded beyond the local network) to every computer on the networks your computer is connected to:

  • every 5 seconds a presence signal with program name, version, a random ID that is new on every start and – once you have entered them – your name and place;
  • every message and every EMERGENCY notice you write, with name, place, program, text and time;
  • a sign-off when quitting;
  • when NET Link starts a network check, one answer per network adapter with the IPv4 address of that adapter. It is addressed to the NET Link that asked, but like everything else it goes to the whole local network via multicast.

For technical reasons every data packet carries your computer's IP address (on the local network also the hardware address of the network card).

Who can read along: Anyone running a suite program or any network tool on the same network can read and write. There is no sign-in and no encryption, and senders can be forged. The programs in the room pass recent messages on to newcomers. A sent message cannot be recalled. Do not write anything confidential there.

What Link-Suite stores: Messages are only kept in memory (at most 200) and are gone when you quit; they never go into a file or the log. What ON THE NETWORK shows about other computers (program, name, place, address, version) is also only kept in memory. Your name, place, whether the chat is on, language and day/night are stored in the file suite.json in the Link-Suite data folder (macOS: ~/Library/Application Support/Link-Suite, Windows: %APPDATA%\Link-Suite). The other suite programs on your computer read this file too, so the settings apply everywhere. Settings that concern only Link-Suite are kept next to it in launcher.json. Both files stay on your computer.

Who is responsible: We are not the controller for the chat within the meaning of the GDPR: we only provide the program, receive no chat data and have no access to it. The participants in the room process your details in their own programs. If you use the chat purely privately, the GDPR does not apply to it (Art. 2 (2) (c) GDPR). If an organiser, company or team uses it professionally, they are usually the controller and your contact for access and deletion.

Logs on your computer

For troubleshooting, Link-Suite writes a small log (logs/main.log and the older main.log.1 in the data folder, at most 256 KB each) with events and errors: version, system, window, GitHub requests, installations, program paths and error messages. It contains no chat texts and no chat names; the path of your user folder is written as “~”. The result of a self-update is briefly kept in self-update.log; Link-Suite reads and deletes the file on the next start. The files stay on your computer and are never sent.

Developer projects

A developer project you start in Link-Suite is a program of its own. What it does and which data it processes is up to the project.
