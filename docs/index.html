Security & privacy

Listens. Shows. Asks.

Every program of the Link-Suite follows the same rules – Link-Suite itself included.

Only listens

Link-Suite controls no device and no program on the network. Other computers are shown, never touched.

No telemetry

No usage data, no crash reports, no tracking. This website has no trackers and no cookies either.

No server, no account

The suite chat runs directly between the programs on the local network. No sign-in, anywhere.

GitHub only

Link-Suite goes online only to ask GitHub for new versions and to download what you choose.

Nothing without a click

Programs are installed, updated and started only when you want.

The chat is deliberately simple and unencrypted: anyone on the same network can read along, and the programs in the room pass recent messages on to newcomers. Do not write anything confidential there. A developer project you start is a program of its own – what it does is up to the project.

How Link-Suite checks every download
  • Only from the program's repository, only over HTTPS from GitHub.
  • Size and SHA-256 must match the checksum GitHub states for the release. If it is missing, Link-Suite does not install and opens the release page instead.
  • The content must match: exactly one program, with the right ID and version.
  • Running programs stay untouched: a program is replaced only once it has quit.

The checks protect against broken and swapped downloads. Link-Suite and the suite programs are published without an Apple or Microsoft certificate; Link-Suite does the checking itself.

First start

Link-Suite is a free project and is published without an Apple or Microsoft certificate. So your system asks once on the first start – here is how to continue. Only download Link-Suite from this page or from GitHub.

macOS

  1. Open the .dmg and drag Link-Suite into the Applications folder.
  2. Start Link-Suite. If macOS says it could not verify the app, click Done.
  3. Open System Settings → Privacy & Security and click Open Anyway next to Link-Suite, then Open.
  4. Allow Local Network – for the suite chat and ON THE NETWORK.

Tip: if macOS asks about the local network again after an update, simply allow it again.

Windows

  1. Start Link-Suite-windows.exe.
  2. If Windows shows “Windows protected your PC”: More info, then Run anyway.
  3. The installer sets up Link-Suite for your user – without admin rights.
  4. If Windows Firewall asks: allow Private networks (for the suite chat).

FAQ

Good to know

What does Link-Suite cost?

Nothing. Link-Suite and every program of the suite are free and open source (EPL-2.0) – no subscription, no account, no ads.

Do I need Link-Suite to use the programs?

No, every program also runs on its own, and the individual downloads stay in the GitHub releases. Link-Suite just makes installing, updating and keeping track easy.

Does it work without internet?

Yes. Starting, ON THE NETWORK and the suite chat run entirely on the local network. Link-Suite only needs the internet to install and update.

How does Link-Suite stay up to date?

Under Settings → About, Link-Suite shows new versions, downloads them, checks them and puts them in place with “Restart now” – on the Mac and on Windows.

Is Link-Suite available in German?

Yes. Switch the language at any time with DE | EN at the top of the window – and every suite program follows.

Does Link-Suite run on Intel Macs?

Yes, there is a separate version for Macs with an Intel processor, macOS 13 and later.

What is EMERGENCY?

A conspicuous notice to every suite program on the network when the team must know right away. EMERGENCY does not replace announcements, radios or the event's safety concept.

Where do I get help?

On the Link-Suite Discord or by mail to fehlermelden@nextphilm.de.
